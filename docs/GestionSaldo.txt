ENTRADAS: Un número de cédula del emisor (Pana), un número de cédula del receptor (Recarga) y un monto positivo.
PRECONDICIONES: 

ESPECIFICACIONES:
- Si cedulaPana == cedulaReacarga, permite recarga a cualquier Rol (excepto Exonerado).
- Si cedulaPana != cedulaReacarga, el emisor debe ser Rol "Estudiante" y no Exonerado.
- Si monto <= 0 entonces retorna false.

SALIDAS:
1- null = éxito
2- String = mensaje de error
