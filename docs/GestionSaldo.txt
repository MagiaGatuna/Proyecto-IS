ENTRADAS: Un número de cédula del emisor, un número de cédula del receptor  y un monto positivo.
PRECONDICIONES: El archivo usuarios.json debe existir y ser accesible.

ESPECIFICACIONES:
- Si la operación es exitosa (se actualiza el saldo), el método retorna null.
- Si hay un error (cédula inexistente, monto <= 0, reglas de rol o estado), retorna un String con el mensaje de error.
- Regla 1: Si no eres Estudiante, solo puedes recargarte a ti mismo (Autopago).
- Regla 2: El receptor SIEMPRE debe ser de rol "Estudiante".
- Regla 3: No se permite recargar a estudiantes con estado "Exonerado".

SALIDAS:
1- null (Éxito)
2- String (Mensaje de error específico)
